Thaw · Goals

Mockups for the Goals feature, built on the existing Thaw system. iPhone 390×844 frames, light mode. Sample data: fun money S$300 a month, payday on the 25th, scenario dates in Nov–Dec 2026.

Goals are optional and never block thawing or review. Each month's pending pool is what you skipped plus the fun money you didn't spend. At month end the pool lands in goals: the earliest deadline fills first, and anything left over goes to the next goal.

Notes for engineering

Reused componentsWant card (goal card is the same shell plus a tag row), fun-money meter (goal detail header), settings rows (deadline toggle and date), choice rows, pill buttons, modal sheet with X close, system action sheet for discard.
New tokensFrost #D9EEF5 for the pending pool and the "Fills first" tag, with text #08506A (AA on Frost). Extended tag uses glow #FBE3D3 with #7A3407 text. Destructive text #B3261E.
Fill orderSort goals by deadline ascending, with goals that have no deadline last (oldest first). The first goal gets the "Fills first" tag. The month-end pool fills goals in that order, and any leftover goes to the next goal. If every goal is full, the remainder stays in Kept.
Pending poolPool = prices of wants skipped this month + fun money left unspent at month end. "S$X pending" updates live: the skipped part with each skip, and the unspent part as fun money is used. Hide the pool line when there are no goals. A pool bigger than the next goal's gap finishes that goal and flows to the next one.
Deadline passedExtend silently by one payday cycle, add a History row, and show the "Extended" tag. No notification. If extended more than once, the tag stays "Extended" and History lists each move.
Dynamic TypeAt AX3 and above, card rows switch from horizontal to stacked (UIStackView.axis = .vertical), and tags move onto their own line. The display font scales via UIFontMetrics. See 1b.
